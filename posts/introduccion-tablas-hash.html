Introducción a las Tablas Hash

Inicio

¿Qué es una Tabla Hash?

Una tabla hash asocia claves a valores mediante una función hash que produce un índice en un arreglo. Es la base para búsquedas rápidas.

  • Clave: identificador.
  • Valor: datos asociados.
  • Función hash: mapea clave → índice.
  • Colisión: dos claves con mismo índice.

Rendimiento

Operaciones promedio: O(1) para insertar, buscar y eliminar cuando la carga y la función hash son adecuadas.
