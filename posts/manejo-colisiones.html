Manejo de Colisiones en Tablas Hash

Inicio

Introducción

Cuando dos claves mapean al mismo índice ocurre una colisión. Las dos estrategias principales son encadenamiento (chaining) y direccionamiento abierto (open addressing).

1. Encadenamiento (Chaining)

Cada posición del arreglo mantiene una lista (o vector) de pares clave–valor. Al ocurrir una colisión se agrega el nuevo elemento a la lista.

// pseudocódigo (insert)
index = hash(key) % capacity
list = buckets[index]
list.append((key,value))

2. Direccionamiento Abierto (Open Addressing)

Los elementos se almacenan directamente en el arreglo; si hay colisión se busca otra celda libre según una secuencia (probe sequence).

Métodos comunes: linear probing, quadratic probing, double hashing.

// linear probing (insert)
index = hash(key) % capacity
while table[index] is occupied:
  index = (index + 1) % capacity
table[index] = (key,value)
