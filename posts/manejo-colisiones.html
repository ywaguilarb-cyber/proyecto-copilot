Manejo de Colisiones en Tablas Hash

Inicio

Introducción

Una colisión ocurre cuando dos claves producen el mismo índice. Las dos soluciones comunes son:

Encadenamiento (Chaining)

Cada bucket contiene una lista de pares clave–valor; nuevos pares se añaden a la lista del bucket.

// insert (chaining)
idx = hash(key) % capacity
buckets[idx].append((key,value))

Direccionamiento Abierto (Open Addressing)

Los elementos se guardan en el arreglo; al colisionar se aplica una secuencia de sondeo (p. ej. linear probing).

// linear probing (insert)
idx = hash(key) % capacity
while table[idx] occupied:
  idx = (idx + 1) % capacity
table[idx] = (key,value)
