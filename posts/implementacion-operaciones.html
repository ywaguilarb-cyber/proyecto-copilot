Operación: Insertar (put)

Paso básico: calcular hash, obtener índice y almacenar allí (o en la estructura de colisión correspondiente).

// put pseudo (chaining)
index = hash(key) % capacity
if buckets[index] contains key: update value
else: buckets[index].append((key,value))

Operación: Buscar (get)

// get pseudo (chaining)
index = hash(key) % capacity
for (k,v) in buckets[index]:
  if k == key: return v
return null

Operación: Eliminar (delete)

En chaining: quitar el nodo de la lista. En open addressing: marcar la celda como "deleted" (tombstone) para preservar la secuencia de sondeo.

// delete pseudo (open addressing)
index = hash(key) % capacity
while table[index] not empty:
  if table[index].key == key:
    table[index].markDeleted()
    return
  index = (index + 1) % capacity
