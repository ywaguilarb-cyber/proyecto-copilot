Insertar (put)

Calcular índice con la función hash y almacenar en el bucket o en la celda resultante según la técnica.

// put (chaining)
idx = hash(key) % capacity
if key in buckets[idx]: update value
else: buckets[idx].append((key,value))

Buscar (get)

// get (chaining)
idx = hash(key) % capacity
for (k,v) in buckets[idx]:
  if k == key: return v
return null

Eliminar (delete)

Chaining: eliminar el nodo del bucket. Open addressing: marcar la celda como "deleted" (tombstone).

// delete (open addressing)
idx = hash(key) % capacity
while table[idx] not empty:
  if table[idx].key == key:
    table[idx].markDeleted()
    return
  idx = (idx + 1) % capacity
