# proyecto-copilot
Proyecto de prueba para Estructura de Datos 2

Preview local (rápido)

Usa Python para servir archivos estáticos desde la raíz del proyecto (PowerShell):

```powershell
python -m http.server 8000
# abrir http://localhost:8000
```

Alternativa con Node.js (si `http-server` disponible):

```powershell
npx http-server -c-1 . -p 8000
```

Estructura esperada

- `index.html` — portada del blog
- `posts/` — artículos en HTML
- `assets/css/` — estilos
- `assets/js/` — scripts

Si quieres que cree o actualice más contenido, pídemelo y lo hago.
